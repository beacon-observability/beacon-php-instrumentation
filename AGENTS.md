# Repository Collaboration Guidelines

- Always communicate in English and write all documentation in English.
- This repository maintains only Beacon PHP's native `opentelemetry` extension. `beacon-php` handles the Agent and dependency orchestration for official OpenTelemetry component packages. Framework-level span logic must not be added to this repository.
- `origin` is the Beacon downstream repository. `upstream` is used only to read official OpenTelemetry history; never push to `upstream`.
- Upstream synchronization must use a pinned tag and a full commit hash. Merge on a separate branch first, then update `beacon/upstream.lock.json` and complete extension testing.
- Preserve upstream compatibility for `OpenTelemetry\\Instrumentation\\hook()`. Beacon-specific changes must have tests and must not break manual instrumentation.
- Before a release, verify the Beacon product version, official extension baseline, version embedded in the extension, cross-platform artifacts, and checksums.
- Official artifacts must be generated by the version-tag workflow and made public only after checksum verification and installation revalidation. Never use branch build artifacts as official installation sources.
