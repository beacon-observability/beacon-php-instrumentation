# Beacon PHP Instrumentation 1.1.0

Beacon product 1.1.0 adopts OpenTelemetry PHP instrumentation extension 1.5.0
at `dd0e147a80d0aeac15c95ec119b146c0b2bc3285`. The native module version is
1.5.0 and its distribution identity remains Beacon. Product version 1.1.0
identifies the release assets independently of the upstream module version.

The baseline includes constant-expression handling for span attributes and
WithSpan arguments, exception/exit handling and observer lifetime regression
fixes. The compatible `OpenTelemetry\Instrumentation\hook()` API is retained.
Framework spans continue to be supplied by official Composer instrumentations.

Candidate builds cover PHP 8.2, 8.3 and 8.4: Linux x86_64/arm64 NTS, macOS
arm64 NTS, and Windows x64 NTS/TS. Windows PHP 8.2/8.3 use VS16 and PHP 8.4
uses VS17. Official binaries must come from the signed version-tag workflow,
with checksums verified before publication and installation revalidation.

The Beacon PHP Agent's existing default extension pin is not changed by this
native-extension release. Select the matching release artifact explicitly until
an Agent adoption update is independently validated.
